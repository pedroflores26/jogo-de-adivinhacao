# Jogo de Adivinhação

Projeto da Aula 15 — Navegação entre Activities e Transferência de Dados.

## Funcionalidades

- Duas Activities
- Navegação com Intent
- Transferência de dados com putExtra()
- Recebimento com getStringExtra() e getIntExtra()
- Escolha de limite: 10, 50 ou 100
- Número secreto aleatório
- Contagem de tentativas
- Dicas de número maior ou menor
- Dicas Quente ou Frio
- Botão Jogar de novo usando finish()

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra a pasta `JogoAdivinhacao` no Android Studio.
3. Aguarde o Gradle sincronizar.
4. Execute no emulador ou celular.

## Activities

- MainActivity: recebe nome e limite.
- JogoActivity: recebe os dados pelo Intent e executa o jogo.
